# 文件浏览器：当前目录、上传与文件操作

## 目录选择与上传

- 点击目录会将它设为当前激活目录，同时展开/收起目录；点击文件使用它的父目录。Git 变更列表中打开文件也会更新当前目录。
- 顶部显示当前目录，提供“项目根目录”和“上一级”按钮。工具栏上传使用这里的目录，而不是固定使用聊天 cwd；不会改变 Agent 的工作目录。
- 选择上传文件时固定目标目录。后续导航、切换项目、同名文件的替换/跳过重试均不能悄悄改掉这个目标。提示和上传结果都显示实际目标路径。
- 可把本地文件拖到文件浏览器：拖到目录行使用该目录，拖到文件行使用其父目录，空白处使用当前目录。聊天输入框的附件上传仍使用聊天 cwd，不与浏览器选择混用。
- 检查、传输、等待服务器保存均显示 spinner；进度到 100% 只表示请求体已传输，收到服务器结果后才结束。收起文件浏览器不会销毁进行中的上传，标题仍显示忙碌状态。
- 保留单文件 25MB、每批合计 100MB 的限制与显式冲突选择；新增客户端预检、防重复提交。Linux 上在读取 multipart 之前固定目录文件描述符，避免目录被移动/替换成符号链接后写错位置。普通文件先完整写入临时文件，再独占发布或原子替换；写入失败不会先删除原文件。

## 菜单与确认

右键文件/目录，或点击每行的“⋮”；手机同样通过“⋮”操作。当前目录按钮和空白处也提供菜单。

- 复制、剪切、粘贴、移动到、重命名。
- 新建文件、新建目录、上传到此目录、复制路径；文件还可下载。
- 删除使用页面内明确确认，默认焦点为取消，Escape 仅取消当前操作。输入名称/目标目录使用页面内表单，不调用浏览器 `alert/prompt/confirm`。
- 文件剪贴板只在当前标签页内存保存路径引用和版本标记；不是系统文件剪贴板，不保存文件内容。剪切到确认粘贴前不改变源文件，收到移动成功确认才清除剪贴板。粘贴可更改目标名称，不自动覆盖同名项。
- 当前支持单项或整个目录操作，不提供多选批量删除。移动/删除后刷新文件树和 Git 状态；已打开的旧路径预览需从新路径重新打开。

## 后端限制与安全

`POST /api/file-operations` 是独立的文件操作入口，不通过 Agent 执行任意命令，不修改 Agent 的权限或配置。

- 请求独立检查网页登录与 Host/Origin，限制 JSON 为 16 KiB；固定操作枚举，移动/删除要求 `confirm: true`。源和目标仍须在既有 `getAllowedFileRoots()` 授权范围内，不因浏览器输入路径而新增授权根目录。
- 菜单按需获取 `type=entry` 的不透明版本标记；不为目录列表增加逐项 stat。源条目已变化时返回 409，要求刷新重新选择。目标已存在时拒绝，不合并目录、不静默覆盖。
- 禁止移动/删除注册的项目根目录及其祖先，禁止直接操作 `.git` 元数据路径，禁止将目录复制或移入自身。多个网页文件操作串行执行，忙碌时要求手动重试。
- 当前文件操作后端支持 Linux：逐级打开不跟随符号链接的目录描述符，通过 `/proc/self/fd` 固定目录。普通文件移动使用独占硬链接后移除原目录项；同文件系统目录移动使用固定 `/usr/bin/mv --no-clobber --no-target-directory`，不启动 shell、不继承 Agent/网页登录环境，并核对移动后的身份，而不是只相信退出码。
- 符号链接复制、移动、删除仅作用于链接本身，不读取或删除其目标。目的目录若经过链接，仍须解析到授权根范围内。设备、FIFO 等特殊文件不支持。
- 跨文件系统复制可以使用；跨文件系统移动明确拒绝，可手动复制后再删除。递归复制/删除最多 10,000 项、64 层；复制合计上限 512MB，超限在修改前拒绝。大目录请使用终端。
- 这不是对抗同 UID 本地进程的沙箱，也不是文件系统事务。不要同时在终端修改正在操作的同一棵目录。遇到并发变化、I/O 错误或断网，可能留下部分副本或部分删除；界面明确提示检查源与目标，不自动重试或清扫未知文件。无回收站，删除确认会说明不可撤销。

## 验证范围

使用独立 HOME、合成项目/文件和已有依赖；所有 Agent 请求在浏览器验证中替换为假响应，文件操作则使用候选构建的真实接口。覆盖当前目录上传、冲突重试目标固定、spinner、复制/剪切/粘贴、目录重命名/删除、确认取消/重复提交、过期版本、路径权限、符号链接、HTTP 鉴权和手机触摸菜单。没有读取真实聊天正文、调用真实模型、安装依赖或用用户文件做移动/删除测试。
