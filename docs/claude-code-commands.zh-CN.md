# Claude Code 斜杠命令

选择 Claude Code 会话后，在输入框输入 `/`，即可搜索本机会话原生提供的命令；点击或用方向键、Tab / Enter 选中，再填写参数并发送。

## 接入方式

- `get_commands` 调用当前 Claude SDK Query 的 `supportedCommands()`，不扫描、复制用户的技能或配置文件，也不为读取目录发送模型提示。
- 列表显示 `Claude Code` 分组、原生描述和参数提示。项目技能、插件命令及别名以本机 CC 实际返回的目录为准；每次重新打开菜单都会刷新目录。
- 原生命令优先于同名网页快捷命令。例如本机提供 `/usage`、`/compact`、`/help` 时，不会被网页的旧统计、压缩或帮助逻辑截获。
- 命令和参数保持原样，经已有 prompt / SSE 链路交给 CC；原生工具审批、停止和完成规则不变。
- `system/local_command_output` 作为助手文字显示并写入网页显示投影。收到原生 `result` 才结束运行状态，不把一条输出当作执行完成。
- 原生目录中的直接命令名优先于别名；同名内置命令优先于被遮蔽的项目命令。未提供的命令明确拒绝，不把拼错的命令悄悄当作普通模型提示。

## 保留的边界

网页不是完整终端。登录/退出登录、终端布局或输入设置，以及网页尚不能跟踪的会话身份/历史切换操作不转发。原生明确标注为 terminal-only 的命令也不展示。`/new`、`/clear`、`/resume` 使用现有网页会话控件；其余不支持的操作请在本机 `claude` 中执行。

菜单读取本身不发送模型请求，但原生初始化可能加载 CLI 允许的项目资源。**用户发送的技能、审查、压缩等命令可能调用模型并消耗额度**；不能因为输入以 `/` 开头就认为免费或只读。
