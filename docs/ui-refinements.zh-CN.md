# UI 精简、子任务详情与草稿

本轮源码改动：

1. 非 Git 目录不再显示仅 Git 根目录的工作树提示。
2. 删除文件浏览器当前目录操作说明，保留实际目录与按钮。
3. 设置、技能、用量面板去掉说明段落；保留字段、数据、错误状态及简短的更新中断确认。
4. 引擎选择移到顶栏颜色选择器之前。仅允许选择已检测为安装的引擎；缺失显示“（未安装）”，检测期间禁用。小屏顶栏允许换行，避免遮住右侧面板按钮。旧会话仍固定原引擎。
5. 点击任务行打开右侧子任务详情标签页；详见 [子 agent 状态](./subagent-status.zh-CN.md)。对话接口仅查询已关联子任务，不接受任意文件路径或外部线程 ID。
6. 草稿文字保存在浏览器 localStorage，按会话或“引擎 + 新建目录”隔离；图片仍只保存在内存。刷新恢复，发送成功后才清除；失败、未确认的发送和等待期间的新编辑保留。新会话获得正式 ID 时迁移未发送草稿，不因切换引擎或点新聊天删除草稿。存储受限时退回内存，不阻断输入。

7. 已发文字提供常驻“编辑”快捷操作，放回输入框，不改写已消费的历史。输入框已有草稿时先确认；确认期间草稿再变化则不覆盖。需要用户再次发送。
8. 排队消息提供独立“撤回”，不自动放回草稿或停止 Agent。Claude 按原生 UUID 取消；OMP 使用其原生 queue + text 移除命令；已消费／未确认的消息不报告成功。Pi 无对应接口时禁用，Codex 不伪造队列入口。“取回编辑”仍作为独立操作保留。

输入框现固定为一个挂载实例，避免空白页转为正式聊天时旧实例的发送确认无法清除新实例草稿。
