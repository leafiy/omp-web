# UI 精简、子任务详情与草稿

本轮源码改动：

1. 非 Git 目录不再显示仅 Git 根目录的工作树提示。
2. 删除文件浏览器当前目录操作说明，保留实际目录与按钮。
3. 设置、技能、用量面板去掉说明段落；保留字段、数据、错误状态及简短的更新中断确认。
4. 引擎选择移到顶栏颜色选择器之前。仅允许选择已检测为安装的引擎；缺失显示“（未安装）”，检测期间禁用。小屏顶栏允许换行，避免遮住右侧面板按钮。旧会话仍固定原引擎。
5. 点击任务行打开右侧子任务详情标签页；详见 [子 agent 状态](./subagent-status.zh-CN.md)。对话接口仅查询已关联子任务，不接受任意文件路径或外部线程 ID。
6. 草稿文字保存在浏览器 localStorage，按会话或“引擎 + 新建目录”隔离；图片仍只保存在内存。刷新恢复，发送成功后才清除；失败、未确认的发送和等待期间的新编辑保留。新会话获得正式 ID 时迁移未发送草稿，不因切换引擎或点新聊天删除草稿。存储受限时退回内存，不阻断输入。

7. 已发文字提供“编辑”快捷操作，与“复制”处于同一个 hover 操作区，样式与显示时机一致；放回输入框，不改写已消费的历史。输入框已有草稿时先确认；确认期间草稿再变化则不覆盖。需要用户再次发送。
8. 四引擎的网页 Follow-up 统一进入服务端待发送队列，均支持单条“撤回”和“取回编辑”；只有尚未交付的项才报告移除成功。Steer 仍按原生能力处理。交付未确认时暂停自动发送，只允许恢复副本，不伪装取消成功。详见 [队列与编辑](./queued-message-editing.zh-CN.md)。

输入框现固定为一个挂载实例，避免空白页转为正式聊天时旧实例的发送确认无法清除新实例草稿。

## 会话列表标题

- 左侧会话列表显示 Agent 的会话名称／标题，不再用首条用户输入代替；尚未命名时显示“未命名会话”。
- 仅为此版本启动后新建的网页会话自动命名：首轮回答完成、原生后台任务与 Follow-up 队列空闲后，使用对应原生 Agent 与当前模型执行一次独立命名请求。已有标题优先；旧会话、恢复的会话不补名。命名失败会提示，不伪造标题或自动重试。
- 命名只使用首条请求与回答各最多 3000 字符的文本，不带工具输出或图片，不把命名提示／回答写入聊天正文。OMP / Pi 通过原生扩展清空活动工具并阻止调用；Claude 使用无工具、无 MCP 的非持久化单轮请求；Codex 使用原生临时结构化请求的空环境方案。模型与登录仍由各 CLI 管理，没有复制凭据或更换模型。
- 生成期间手动命名、清空名称、停止、切换分支或销毁会话会取消自动写入；写入前再次检查原生名称。标题变化独立于任务完成通知，不播放额外完成音效。
- OMP `session_info_update`、Pi `session_info_changed` 和既有状态查询发现的名称变化会更新当前会话及侧栏。旧列表响应不能覆盖新刷新结果，旧状态响应不能覆盖新标题通知；SSE 重连可恢复生成的标题。
- 固定宽度 OMP 标题槽只读处理；追加式 `session_info` 名称由完整索引取得最新值，避免前 64 KiB 内的旧名称覆盖后续重命名或清空。

### Claude 原生标题（2026-11-08 修复）

此前 Claude 会话在侧栏几乎总是“未命名会话”，而 OMP 会话有标题，原因是两类标题来源不同：

- OMP 原生自动命名写入自己的标题槽，侧栏直接读取。
- Claude Code 把自动生成的 `ai-title`（以及 `/rename` 的 `custom-title`）写在**原生**会话 JSONL（`~/.claude/projects/...`）里；网页投影只记录网页重命名，侧栏也只读投影，所以从未显示 Claude 自己的标题。

现在：网页重命名优先；投影没有名称时，通过 SDK `getSessionInfo(id, { dir: cwd })` 只读取 `customTitle`（即 custom-title，否则 ai-title），不使用会回退到首条提示的 `summary`，不写原生文件。侧栏列表按投影修改时间缓存（找到 5 分钟、未找到 30 秒）；活动会话在每轮结束及恢复时刷新原生标题，变化时推送 `session_info_update` 并使侧栏缓存失效，SSE 重连可恢复。状态里已有原生标题时，网页自动命名直接跳过，不再额外请求模型。清空网页名称会回到 Claude 原生标题。

#### 新会话的标题与侧栏出现时机

- Pi / OMP 在第一条助手消息完成前不写会话文件，侧栏只列出磁盘上的会话，所以新会话以前要等首轮回复结束才出现。现在本标签页刚创建的会话会先以乐观行显示在侧栏（使用所选目录归组），文件写入后由服务端列表接管；收到 `session_info_update` 时这一行的标题同步更新。
- Claude 一般在首轮早期就写入 `ai-title`。首轮出现主线程回复后，每 4 秒读取一次原生标题，找到或回合结束即停止，不再等到回复完成。OMP 原生标题本来就在首轮中途推送。Pi / Codex 没有原生自动标题，网页命名需要首轮回答文本，仍在首轮结束后出现。
- 修复：上一版本让 Claude 在回合结束时推送标题，浏览器收到后使历史缓存失效，而失效会中止正在进行的历史加载，界面显示 `AbortError: signal is aborted without reason`、新对话无法打开。现在缓存失效只是不再缓存进行中的请求，不会中止调用方；被取代的请求不报错；SSE 重连重放的相同标题不再触发历史和侧栏重载。

仍显示“未命名会话”的情况：Agent 从未命名过的会话，例如功能上线前的旧 OMP 会话（标题槽为空且无 `title_change`）、只有极短对话的 Claude 会话、尚未完成首轮的新会话。仍不使用首条用户输入代替标题。

## 侧栏：项目 → 历史会话

参照 Codex 桌面端：

- 侧栏不再有“选择项目”下拉。所有会话按 project root 分组（worktree 归入主仓库），项目按最近活动排序；可折叠，折叠状态存于 localStorage（默认展开最近 5 个和当前会话所在项目）。每个项目先显示 5 个顶层会话，其余“再显示 N 个”。分叉会话仍缩进在父会话下。
- 会话行单行显示标题、引擎、相对时间；悬停或选中时显示重命名／删除。折叠的项目行汇总运行中／新活动状态。搜索按钮可按路径、会话名或首条消息筛选。
- 有提问／审批弹窗等待回答的会话显示琥珀色问号徽标（优先于运行中／新活动，折叠的项目行同样汇总）。状态来自 `/api/agent/running` 的 `waitingSessionIds`（三种引擎各自的待处理弹窗），随可见页轮询更新；非当前会话出现新提问时侧栏播放提示音，当前会话仍由聊天窗口播放；页面加载时已存在的提问只显示徽标不响铃。各处 `useAudio` 共享同一个 AudioContext 和开关状态。
- 侧栏顶部刷新按钮旁的“+”（新建会话）打开空白聊天，默认目录 `/tmp`；目录在聊天输入框上方的目录按钮中选择（`/tmp`、最近项目、worktree、浏览文件夹、自定义路径），新建／删除 worktree 也移到这里。项目行的铅笔按钮直接以该项目为目录新建。更换目录会重开空白聊天并迁移未发送草稿；发送首条消息后目录固定。Ctrl+Alt+N 与“新建会话”一致。
- 没有选中会话时显示 `/tmp` 的空白聊天。Explorer 跟随当前聊天目录。切换到其他项目的会话会关闭右侧文件标签。
